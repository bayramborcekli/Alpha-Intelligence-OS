Amaç:
Mission 1500.1 Intelligence katmanı için güvenli, deterministik,
JSON-serileştirilebilir ve açıklanabilir veri sözleşmelerini oluştur.

Bu agent yalnızca veri modelleri ve bunların testleri üzerinde çalışmalıdır.
Route, UI, servis orkestrasyonu, harici LLM, geçmiş kaydı veya exchange
entegrasyonu eklememelidir.

Önerilen dosya:
- intelligence_api.py

Ancak mevcut mimariye daha uygun ayrı bir model dosyası gerekiyorsa:
- intelligence_models.py

Yeni bir paket/dizin yapısı oluşturmadan önce mevcut düz modül desenini koru.

Gerekli modeller:

1. ConfidenceLevel
   Değerler:
   - HIGH
   - MEDIUM
   - LOW
   - INSUFFICIENT_DATA

2. IntelligenceStatus
   Örnek değerler:
   - OK
   - PARTIAL
   - STALE
   - UNAVAILABLE

3. DataFreshness
   Alanlar:
   - status
   - observed_at
   - age_seconds
   - source
   - detail

4. IntelligenceEvidence
   Alanlar:
   - source
   - field
   - value
   - unit
   - observed_at

5. IntelligenceInsight
   Alanlar:
   - code
   - category
   - title
   - observation
   - reason
   - impact
   - recommendation
   - confidence
   - evidence
   - freshness
   - advisory_only

6. IntelligenceSummary
   Alanlar:
   - status
   - generated_at
   - portfolio_summary
   - risk_summary
   - insights
   - recommendations
   - warnings
   - freshness
   - advisory_only

Zorunlu davranışlar:

- Finansal değerler bellekte Decimal olarak tutulmalı.
- JSON dönüşümünde Decimal için mevcut proje standardını kullan.
- Mevcut standart yoksa Decimal değerleri kesinlik kaybetmeden string olarak
  serileştir.
- float dönüşümü yapma.
- Bilinmeyen finansal değerleri sıfır olarak gösterme.
- Eksik değer için null veya açık bir unknown durum kullan.
- UI metni gerekiyorsa Türkçe "Veri Yok" kullanılabilir.
- advisory_only her insight ve summary için true olmalı.
- Modellerde order_action, side, quantity_to_trade, target_price,
  leverage_instruction veya benzeri işlem talimatı alanları bulunmamalı.
- raw credential, request headers, session, cookie veya signature alanları
  bulunmamalı.
- Evidence yalnızca izin verilen, doğrulanmış alanlara referans vermeli.
- Enum değerleri bilinmeyen serbest metin kabul etmemeli.
- Aynı model aynı veriden aynı JSON yapısını üretmeli.
- Alan sıralamasına bağımlı olmayan fakat şeması sabit çıktı sağlanmalı.
- Tarihler UTC ve ISO-8601 biçiminde olmalı.
- Naive datetime üretme.
- Kullanıcıya gösterilecek metinler varsayılan olarak Türkçe olmalı.
- Model oluşturulurken HTML kabul edilse bile template katmanında escape
  edilebilir düz metin olarak tutulmalı; Markup/SafeString kullanılmamalı.
