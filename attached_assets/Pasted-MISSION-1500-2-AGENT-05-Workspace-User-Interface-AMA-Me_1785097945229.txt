MISSION 1500.2 — AGENT 05
Workspace User Interface

AMAÇ

Mevcut Workspace Read-Only API uçlarını kullanarak
salt-okunur Intelligence Workspace kullanıcı arayüzünü oluşturmak.

Bu agent yalnızca UI katmanını geliştirecektir.

Servis, Timeline, API, Export ve Security mimarisi değiştirilmeyecektir.

────────────────────────────────────────

GÖREVLER

1.

Yeni şablonu oluştur.

templates/intelligence_workspace.html

2.

Yeni sayfa rotasını ekle.

GET /workspace

3.

Sayfa mevcut

dash_base.html

şablonunu genişletmelidir.

4.

Navigasyona yalnızca bir Workspace bağlantısı eklenebilir.

Mevcut navigasyon yapısı bozulmayacaktır.

5.

Aşağıdaki bölümleri oluştur.

• Zaman Çizelgesi

• Snapshot Detayı

• İki Snapshot Karşılaştırma

• Tavsiye Geçmişi

• Risk Evrimi

• Arama ve Filtreler

• Export bağlantı alanı
  - yalnızca pasif/placeholder veya mevcut GET uçlarına bağlantı
  - yeni export mantığı bu agent kapsamında değildir

6.

Veriler yalnızca mevcut Workspace API uçlarından alınacaktır.

Doğrudan Timeline veya Workspace Service erişimi yasaktır.

7.

Kullanılacak uçlar:

GET /api/workspace/timeline

GET /api/workspace/snapshot/<id>

GET /api/workspace/compare

GET /api/workspace/recommendations

GET /api/workspace/risk-evolution

GET /api/workspace/search

8.

UI salt-okunur olacaktır.

İşlem

Emir

Onay

Silme

Güncelleme

Otomatik karar

butonu eklenmeyecektir.

9.

XSS güvenliği korunacaktır.

intelligence.html içindeki güvenli yardımcı desenler kullanılmalıdır:

esc()

txt()

vy()

failState()

Kullanıcı veya API kaynaklı hiçbir veri doğrudan innerHTML içine
kaçışsız yazılmayacaktır.

10.

Bilinmeyen değerler:

null

↓

"—"

Eksik karşılaştırma tarafı

↓

"Veri Yok"

olarak gösterilecektir.

Asla 0 türetilmeyecektir.

11.

Risk evrimi görselleştirmesi:

• harici kütüphane yok

• harici CDN yok

• CSP uyumlu

• basit yerel SVG, canvas veya tablo tabanlı gösterim

• tahmin çizgisi yok

• trend tahmini yok

12.

Responsive yapı korunacaktır.

Mobil görünümde mevcut

data-l

deseni kullanılmalıdır.

13.

Hata deneyimi sterile olacaktır.

Ham exception

Stack trace

Credential

Secret

API yanıtı içinde olsa bile ekrana taşınmayacaktır.

14.

Sayfa ve API isteklerinde mevcut authentication davranışı korunacaktır.
