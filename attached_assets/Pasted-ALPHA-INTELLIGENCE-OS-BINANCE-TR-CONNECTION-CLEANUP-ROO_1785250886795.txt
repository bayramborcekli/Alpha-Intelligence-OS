GÖREV B — BINANCE TR TEK ADAPTÖR
Binance TR kodunu tek bir sınıf/modülde topla, örneğin:
`binance_tr_client.py`

Sadece şu read-only işlevler:
- get_server_time()
- get_spot_account()

Base:
https://www.binance.tr

Public time:
GET /open/v1/common/time

Signed account:
GET /open/v1/account/spot

Signed query:
timestamp=<server timestamp>&recvWindow=5000
HMAC-SHA256(secret, exact_query_string)
signature query-string sonuna eklenecek.
Header:
X-MBX-APIKEY: <key>

- `requests.Session()`
- Windows'taki çalışan bağımsız teste eşit davranış:
  `session.trust_env = False`
- Binance TR için özel custom CA bundle / certifi+Windows CA birleştirmesi KULLANMA.
  Varsayılan requests TLS verification kullan.
- `verify=False` kesinlikle kullanma.
- response body yalnız JSON parse için kullanılmalı; secret/header/signature loglanmamalı.

GÖREV C — BINANCE TR HATA NORMALİZASYONU
Binance TR cevap modeli `{code,msg,data,timestamp}`.
- code == 0 => success
- non-zero => güvenli hata
- Tanınmayan code'u INVALID_EXCHANGE_RESPONSE diye gizleme:
  UI/diagnostic'e `exchange_code` ve sanitize edilmiş `exchange_message` döndür.
- API key/secret/signature/request URL query ASLA dönme.
- HTTP status, endpoint path, code, msg gösterilebilir.
- HTTP 4xx JSON body varsa code/msg'yi koru.
