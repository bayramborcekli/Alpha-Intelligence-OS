MISSION — FIX BINANCE GLOBAL API PERMISSION VALIDATION

SORUN

Gerçek Windows testinde Binance Global bağlantısı şu mesajla reddedildi:

“Yetki reddedildi — Anahtar işlem/çekim yetkisi taşıyor.”

Mevcut doğrulama muhtemelen:

GET /api/v3/account

cevabındaki:

- canTrade
- canWithdraw
- canDeposit

alanlarını API KEY izni gibi değerlendiriyor.

Bu yanlıştır. Bu alanlar hesap durumudur; API anahtarı izinlerinin kanonik kaynağı değildir.

Binance API anahtarı izinleri yalnız şu resmi endpoint üzerinden doğrulanmalıdır:

GET /sapi/v1/account/apiRestrictions

============================================================
1) KANONİK İZİN KONTROLÜ
============================================================

Binance Global bağlantısında:

1. server time al
2. imzalı GET /api/v3/account ile credential doğrula
3. imzalı GET /sapi/v1/account/apiRestrictions ile gerçek API KEY izinlerini al
4. bağlantı kararını yalnız apiRestrictions cevabına göre ver

/api/v3/account içindeki:

- canTrade
- canWithdraw
- canDeposit

alanlarını API key izin reddi için KULLANMA.

Bu alanlar yalnız hesap bilgi/status alanı olarak saklanabilir.

============================================================
2) READ-ONLY KABUL POLİTİKASI
============================================================

Bağlantı yalnız şu durumda CONNECTED_READ_ONLY olsun:

enableReading = true

ve aşağıdaki tüm tehlikeli izinler false:

enableWithdrawals
enableSpotAndMarginTrading
enableMargin
enableFutures
enableVanillaOptions
enablePortfolioMarginTrading
permitsUniversalTransfer
enableInternalTransfer
enableFixApiTrade

Alanlardan biri true ise:

PERMISSION_DENIED

ve credential saklanmasın.

enableFixReadOnly=true güvenli read-only izin olarak kabul edilebilir.

============================================================
3) UNVERIFIED DAVRANIŞI
============================================================

Credential doğrulaması başarılı fakat:

- apiRestrictions endpointi desteklenmiyorsa
- izin cevabı eksikse
- Binance geçici olarak endpointi döndürmüyorsa

anahtarı yanlış biçimde reddetme.

Durum:

CONNECTED_PERMISSIONS_UNVERIFIED

olsun ve dashboard sarı göstersin.

Ancak gerçek trading/withdrawal izni açıkça true görülürse kesin REDDET.
