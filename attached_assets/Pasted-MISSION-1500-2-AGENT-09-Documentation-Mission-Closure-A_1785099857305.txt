3.

Timeline katmanını belge:

• append-only JSONL

• kayıt sırası eski → yeni

• Decimal → string

• float reddi

• canonical JSON

• dosya ve kayıt boyut sınırları

• file locking

• environment path override

• overwrite/update/delete yok

4.

Workspace Service fonksiyonlarını belge:

• get_timeline(limit, offset)

• get_snapshot(id)

• compare_snapshots(a, b)

• get_recommendation_history()

• get_risk_evolution()

• search(...)

Aşağıdakileri açıkça belirt:

• karşılaştırma derin ve deterministiktir

• liste farkları indeks tabanlıdır

• NEW / CHANGED / REMOVED durumları vardır

• eksik taraf "Veri Yok" olarak gösterilir

• recommendation tekrarları count ile birleştirilir

• risk forecast = null

• tahmin veya trend kestirimi yapılmaz

5.

Workspace API uçlarını belge:

GET /api/workspace/timeline

GET /api/workspace/snapshot/<id>

GET /api/workspace/compare

GET /api/workspace/recommendations

GET /api/workspace/risk-evolution

GET /api/workspace/search

Tüm /api/v1 takma adlarını da listele.

6.

Her API ucu için aşağıdakileri belirt:

• HTTP metodu

• parametreler

• authentication gereksinimi

• başarı durumu

• 400 davranışı

• 404 davranışı

• 405 davranışı

• Cache-Control: no-store, private

• read_only / advisory_only zarfı

7.

GET /workspace

• Risk Evrimi

• Dışa Aktarım alanı

Aşağıdakileri açıkça yaz:

• UI salt-okunurdur

• yalnız Workspace GET API'lerini kullanır

• işlem/emir/güncelleme/silme butonu yoktur

• null → "—"

• eksik karşılaştırma → "Veri Yok"

• XSS kaçışı uygulanır

• harici JS/CSS/CDN yoktur

• CSP ile uyumludur

9.

Export formatlarını belge:

• JSON

• CSV

Aşağıdakileri belirt:

• format=json varsayılan

• json|csv dışı → 400

• Decimal string korunur

• CSV düz metin hücrelerden oluşur

• CSV formül enjeksiyon koruması vardır

• yapısal değerler canonical JSON metnine düzleştirilir

• UTF-8 BOM

• CRLF

• Content-Disposition attachment

• X-Content-Type-Options: nosniff

• Cache-Control: no-store, private

10.

Güvenlik doğrulamasını belge:

• tüm API/export uçlarında authentication

• /workspace anonim erişimde login yönlendirmesi

• yalnız GET/HEAD/OPTIONS

• POST/PUT/PATCH/DELETE → 405

• yeni CSRF istisnası yok

• rate-limit bypass yok

• template autoescape açık

• |safe yok

• path traversal etkisiz

• kullanıcı girdisi dosya yolunu belirleyemez

• exception/stack/path/env/credential/secret sızmaz

• exchange/network/LLM erişimi yok

• history dosyası okuma sonrası bayt-özdeş kalır

• liste karşılaştırması indeks tabanlıdır

• sıra değişimi değişiklik olarak görülebilir

• risk forecast = null

• trend tahmini yoktur
