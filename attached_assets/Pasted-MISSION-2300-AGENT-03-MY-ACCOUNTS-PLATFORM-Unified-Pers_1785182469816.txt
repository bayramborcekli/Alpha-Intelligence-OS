MY ACCOUNTS PLATFORM

ROLE

Create a new Settings module named

"My Accounts"

This page manages ONLY the user's own investment accounts.

The user should configure an account once.

After that, Alpha Intelligence automatically uses it everywhere.

==================================================
CORE PHILOSOPHY
==================================================

Alpha Intelligence is NOT an exchange platform.

Alpha Intelligence is NOT a broker.

Alpha Intelligence is NOT an exchange marketplace.

Alpha Intelligence is an autonomous investment operating system.

The exchanges belong to the user.

The AI simply manages the user's connected accounts.
