Permission Gate
Kill Switch

Risk outcomes:

ALLOW
→ continue

REJECT

REDUCE_SIZE
→ return recommendation only
→ no automatic resizing
→ no PaperBroker invocation

REQUIRE_CONFIRMATION
→ deny in Agent 04
→ no PaperBroker invocation

→ deny
→ no PaperBroker invocation
