7. MODE SAFETY MODEL

Define immutable mode metadata.

Each mode SHALL declare:

PAPER

• exchange_write_allowed = False
• simulated_fill_allowed = True
• broker_read_allowed = False
• human_confirmation_required = False
• explicit_authorization_required = False

SHADOW

• exchange_write_allowed = False
• simulated_fill_allowed = False
• broker_read_allowed = True
• human_confirmation_required = False
• explicit_authorization_required = False

MICRO_LIVE

• exchange_write_allowed = potentially true
• simulated_fill_allowed = False
• broker_read_allowed = True
• human_confirmation_required = True
• explicit_authorization_required = True

Important:

Agent 01 SHALL NOT enable Micro Live.

It only defines its permanent safety contract.

Default runtime state SHALL be non-writing.
