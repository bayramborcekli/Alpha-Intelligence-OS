MISSION 1500.2 — AGENT 04
Workspace Read-Only API

AMAÇ

Workspace servis katmanını kullanarak yalnızca GET tabanlı
Workspace API katmanını oluşturmak.

Bu agent yalnızca API rotalarını geliştirecektir.

UI, Export ve Security doğrulamaları bu agent'ın kapsamında değildir.
