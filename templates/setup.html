🔐 Hash değerini Replit Secrets'a kaydedin

  1. Replit editörünün sol panelinde Tools → Secrets bölümünü açın.
  2. Yeni secret ekle:
    • Anahtar: ALPHA_OWNER_PASSWORD_HASH (veya eski adı ADMIN_PASSWORD_HASH)
    • Kullanıcı adı için: ALPHA_OWNER_USERNAME
    • Değer: Önceki adımda kopyaladığınız hash
  3. Kaydedin.
  4. Uygulamayı yeniden başlatın (Replit'te Run düğmesine basın).
Hash değeri zaten pano'da. Gerekirse önceki adıma dönüp tekrar kopyalayabilirsiniz.
